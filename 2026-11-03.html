"Weight-space programming": GPT-6 Astra reads raw neural-network weights, edits 0.016% of Qwen's and lifts its MATH-500 score from 7.9% to 48.1% with no training loop Hacker News → Takehi et al. · Latent SpaceFed the raw weights of four PPO-trained game policies, Astra named the game for all four; it wrote small networks from scratch that beat 100M-step PPO; 2,628 points, the top story of both days.

Rikiya Takehi, Teoh, Alex Zhang and Omar Khattab (MIT CSAIL) show frontier models can natively read and write network weights. Without environment feedback, GPT-6 Astra wrote game-playing networks that outplayed policies trained with PPO for 100 million steps, identified the weights of diffusion models trained on circles, triangles and squares, and, asked to fix Qwen3.5-0.8B's reasoning loops without gradients, found a weight-level cause and edited 0.016% of the parameters: MATH-500 went from 7.9% to 48.1% and IFEval tripled. The authors' line is that "our neural network weights will soon be natively optimized by LLMs that deliberately reason about their weights." swyx's AINews frames it against Karpathy's "autoresearch" from eight months ago: instead of an agent writing PyTorch and watching loss curves, a smart model edits a dumber model directly, which "cuts autoresearch out of the RSI loop"; his caveats are that this is LLM-driven interpretability on tiny networks and unlikely to scale yet, though an independent reproduction has already appeared. Read it next to the Anthropic filing below, which uses the same acronym.

Rocky Linux's creator had an AI agent build "Ginux", a from-scratch Rust kernel that runs unmodified Linux binaries, in 11 days Slashdot → It's FOSSNot a fork: its own memory management, scheduler, process model, filesystems and networking, with the Linux ABI exposed as a "personality." Runs only in QEMU, no GPU or NVMe, no security audit.

Gregory Kurtzer, who created CentOS and Rocky Linux and co-founded CIQ, released Ginux: an independent, Rust-first x86-64 kernel written mostly by an AI agent over 11 days, explicitly not derived from Linux. It implements the Linux ABI so existing binaries run unmodified; in the project's framing Linux is a personality Ginux presents rather than the kernel underneath. The caveats are the whole story for now: QEMU only, no physical-hardware profile, no GPU or NVMe support, and nobody has audited it. The useful read is as a data point beside Sunday's Cisco card and the Pando story below: the "AI rewrites a systems layer in days" claim is now being made by people with the credentials to be taken seriously, and the gap between "boots in an emulator" and "I would run it" is where the next year of argument lives.
