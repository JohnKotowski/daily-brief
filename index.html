Microsoft open-sources Scope, a test harness for whether coding agents can actually use your SDK, CLI or MCP server Slashdot"Developer-agent experience" becomes a measurable thing; Cosmos DB used it to close 47 doc and kit issues.

Scope (MIT licence, runs on Kubernetes) sets up repeatable experiments in which an agent is handed a task and your package, then reports where it failed to discover a feature, misread the docs, or picked the wrong SDK.
