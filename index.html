Ruby2Shell: a one-byte overflow in Ruby's case conversion is reachable before login on stock Rails Veria Labs · ruby-lang.org · HN 258Another pre-authentication server bug this week, after Java4Shell and NGINX.

Upcasing the letter ß in several legacy single-byte encodings writes two bytes where the code checks room for one, so an input with 21 of them overflows a heap buffer by a byte. The bug has been present since Ruby 2.4.0 and is reached through upcase, swapcase, case-folding downcase and casecmp?. UTF-8 strings take a different path and are not affected. Veria Labs says the bug is reachable in default framework configurations and will publish a proof of concept in a week. The fix is Ruby 3.3.14, 3.4.13 or 4.0.10; the Ruby project's own advisory lists seven vulnerabilities in the regular expression engine and case conversion, all fixed in those releases.
