AI Products

Anthropic launches Claude Ship: agents that review, fix and approve pull requests TechCrunch · SlashdotThe approval agent applies a policy the team writes in plain language as a file in the repository.

Claude Ship is three agents in Claude Code. Code Review is already generally available. PR Steward, in beta, fixes failing CI checks, merge conflicts and review feedback, and comments after every push on what it changed and how to roll it back. Claude Approvals, also in beta, decides whether a change can merge, using a policy file that can draw on Code Review findings or a company's own classifiers. Anthropic suggests running approvals in observe-only mode first. Its blog post says: "On the Claude Code team, Claude writes most of our code, and we wanted everything after the PR to move that fast too." Developers can try it with the new /ship command. This is relevant to the agent fleet's own repositories, where review is the slow step.

Z.ai releases GLM-5.4, its first flagship model built as a "loop transformer" Z.ai · HN 1,122It runs 28 shared layers twice instead of adding parameters; the post gives no benchmark scores.

In a standard transformer each layer runs once per pass. GLM-5.4 runs a group of weight-shared layers for two iterations, which Z.ai says gives deeper reasoning without more parameters. The company did not train it from scratch; it adapted the pre-trained GLM-5 base at 750B scale through continued training, and claims the result is comparable to models of 2 to 3 trillion parameters. It names one limitation: the model "tends to get caught in overly long 'marathon thinking' loops". Z.ai frames the release as the start of "generalized coding", where code is the route to a wider range of tasks. Hacker News commenters pointed out that the post contains no benchmark numbers, so the size-equivalence claim is the company's own.

Andreas Kling announced the alpha on Monday. Ladybird's engine is its own and not a fork of Chromium, WebKit or Firefox.
