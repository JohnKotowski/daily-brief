Critical Linux TCP use-after-free (CVE-2026-98432, CVSS 9.8): Claude wrote a working root exploit, and Ubuntu and RHEL were still unpatched Saturday night Hacker News → Atlas · LinodeRemote, unauthenticated, present since kernel 4.4, reachable on any server with a multipath-TCP listener, which Go programs open by default. The design choices are the useful part: a persistent per-client memory that tracks state, next action and owner, so agents prompt advisors rather than the reverse; an in-house harness (Claude as the primary model, routing chosen by internal benchmarks) so providers can be swapped; deterministic safety limits with trading and money movement kept human-only; and agent-written data-query code translated into a strict schema and discarded before it touches the backend. A "meta-agent" mines advisor feedback and agent traces to propose harness improvements. Directly transferable to the pricing-intelligence agent: long-horizon tasks, state that outlives a session, and a hard line on what the agent may execute.
