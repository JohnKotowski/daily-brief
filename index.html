Google launches the Gemini Decisions API and a new Gemini Decision 1 model that answers up to 1,000 yes/no, multiple-choice or rubric questions in one pass at $0.10 per million input tokens with no output tokens billed Hacker News 432 ptsIndependent testing by Artificial Analysis is more mixed than Google's own benchmarks: 66 on its Decision Index, tied with Jev 1.14 and 7 points behind the leaders.

Gemini Decision 1 (gemini-decision-1) is a non-generative model: it scores candidate options in a single forward pass and returns probabilities with a 0 to 1 confidence score per answer, so code can route ambiguous cases to a fallback or a human. One request takes a shared input of text, images, audio, video or PDFs (up to 256K tokens) plus up to 1,000 independent questions, with 2 to 255 options on multiple choice. Google quotes 150 to 250 ms end-to-end latency and says it is nearly 5x cheaper than Gemini 3.5 Flash-Lite across its benchmark suite; it is available now through the Gemini API in Google AI Studio. Latent Space's AINews reports Google's own tests show it beating TypeSafe's Jev 1.14 on 5 of 7 shared benchmarks, but Artificial Analysis measured $345 per million tasks versus $156 for Jev and $103 for Drex Max, 211 ms per task versus 92 ms for Jev, and all questions correct on only 33% of documents on AA-Paperclip versus 63% for Drex Max. AINews also says the project went from an internal DeepMind prototype to a shipped API in about six weeks, and that LangChain had day-zero support.

AWS open-sources AWS Emulator, a local emulator of the AWS APIs for testing without an AWS account, at no additional service fee Hacker News 847 ptsIt ships an agent skill for setup and an embedded mode that runs one isolated instance per Rust test in-process.

The emulator is a local program with no graphical interface that serves an AWS API endpoint; you point the AWS CLI or an SDK at it with environment variables and run code as usual. Linux gets RPM and Debian packages, while Windows and macOS run it in a container. The repository holds one Rust crate per AWS service, driven by each service's Smithy model, and publishes per-service fidelity scores with every release plus a directory of known gaps. AWS says it is for building and testing only, not for production workloads or security testing. Caveats from the README: building from source needs at least 100 GB of free disk, and telemetry to AWS is on by default.

A critical remote code execution flaw in Apache HTTP Server's HTTP/2 module (CVE-2026-119618) is patched in version 2.4.71; Wiz says 64% of cloud environments have vulnerable resources Hacker News 198 ptsThe bug was found independently by Anthropic and Google Cloud's Vulnerability Research Team; no exploit or in-the-wild exploitation is known yet.

The flaw is a race condition in the assign_headers() function of mod_http2: improper synchronisation between threads sharing resources lets a remote, unauthenticated attacker corrupt heap memory and potentially execute code with the web server's privileges. Wiz reports 51% of cloud environments have publicly exposed instances, though it notes those figures do not account for configuration. The fix is Apache HTTP Server 2.4.71 or later, or a standalone mod_h2 build newer than 2.0.42. Where patching has to wait, the mitigation is to disable HTTP/2 by restricting the Protocols directive to http/1.1. As of Wiz's publication on November 11 there was no public exploit and no report of exploitation.

Researchers trace a 60-second pulse seen on power grids on five continents to uninterruptible power supplies running clock-synchronised battery self-tests SlashdotThe pattern appeared in all four measured buildings that had UPS systems and in none without them.

A team led by physicist Dirk Witthaut of the University of Cologne published the finding in Nature Energy, per ScienceAlert via Slashdot. They analysed high-resolution electricity measurements from buildings on the Forschungszentrum Julich campus in Germany and detected tiny bursts of battery current at exact one-minute intervals, tracing the fluctuation through one building's wiring to its connection with the public high-voltage grid. The manufacturer then confirmed the cause: routine battery self-tests run automatically by the units' management software. Devices in different buildings and countries fire together because they sync their clocks to external time signals. The authors' wider point is that benign control routines can become systemically relevant when many devices act coherently.
