"*sshole": OpenSSH on musl-based Linux (Alpine, OpenWrt) lets attackers log into password-disabled accounts, because musl's crypt() returns "*" on failure — 2,696 points, the biggest security story of the week Hacker News → sshhole.com · SlashdotAlso this week: a "remote code execution" CVE in MS Paint, and CISA warning that internet-connected industrial and military freezers are being mass-hacked.

Accounts with a locked "*" password field are supposed to be unreachable by password. On musl, crypt() returns "*" when it fails, and it fails on any password longer than 256 bytes, so the comparison succeeds and almost any very long password opens the account. Alpine and OpenWrt are the big exposed populations, which means a lot of containers and routers. The write-up includes a demo, a compromise check and the mitigation: disable SSH password authentication, which you should have done anyway. Elsewhere in the week's patch notes: Microsoft rates CVE-2026-83844 in modern Paint as network-exploitable with no auth or interaction (HN is sceptical, since Paint exposes no network service; fixed in 11.2609.401.0), and CISA says an ongoing campaign is compromising internet-connected refrigeration controllers at retail and military sites.

Direct input for any AI-pricing page copy, including the book.

Irrational Labs showed 1,014 US software buyers one of three pages for a real AI product: no agent language, one agent, or a team of agents. The single-agent framing produced a slight, non-significant dip in stated purchase intent; the team-of-agents framing lifted it by 6.3 points (p=0.022) while also raising perceived complexity. Poyar attributes the lift to the "unpacking effect", where naming the parts makes the whole feel more valuable, and is careful that the study measured intent rather than purchases.
