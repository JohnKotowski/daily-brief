OpenAI ships "Lockdown Mode" to blunt prompt-injection attacks TechCrunch A hardened ChatGPT profile that strips out browsing, image retrieval, deep research and agent mode to shrink the data-exfiltration surface.

OpenAI introduced Lockdown Mode, a defensive posture for ChatGPT aimed at organizations handling sensitive data. The threat it targets is prompt injection — malicious instructions hidden inside webpages or uploaded files that hijack the model into leaking data. Lockdown Mode works by disabling the exact capabilities attackers abuse: live web browsing, image retrieval, deep research, and agent mode. OpenAI is candid that it doesn't make ChatGPT immune ("could still be vulnerable"), only that it substantially lowers the odds of exfiltration. It's rolling out to ChatGPT Business and eligible personal accounts — read it as the enterprise market forcing labs to ship security tiers, not just capability tiers.
