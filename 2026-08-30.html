Samsung's Processing-in-Memory at Hot Chips 2026 Chips and Cheese · HN 260 Compute inside the memory stack. Attacks the bandwidth wall that actually bounds LLM inference.

A proper technical write-up of Samsung's PIM work: put arithmetic units inside the DRAM itself so memory-bound operations stop paying the round-trip to the accelerator. LLM inference at batch size 1 is bandwidth-bound, not FLOP-bound, which is precisely the regime PIM targets.

The catch is the same as it's always been — programming model. PIM only pays off if the toolchain exposes it, and that's the gap between an interesting Hot Chips talk and something in a datacentre.
