Google DeepMind's AlphaProof Code formally verified the production code of the Signal protocol in four weeks, with agents writing over six million lines of Lean Google DeepMind · Hacker News 632 ptsAbout 1% of the codebase was flagged for human review; two reintroduced real bugs were both caught.

DeepMind says this is the first time the implementation of a widely deployed cryptographic protocol has been formally verified by any method, with or without AI; earlier work stopped at the design level. Human experts and a mix of models wrote the formal specifications, with every one reviewed by a person, then agents running Gemini Carbon produced the proofs and flagged about 1% of the codebase for human review. As a check, the team reintroduced two real, previously fixed bugs into an isolated copy of Signal's code and the system produced machine-checked proofs that both versions were insecure. Signal CTO Ehren Kret called translating live code into valid Lean theorems "a major breakthrough". DeepMind is open-sourcing the verification artifacts and published a technical paper.

Chrome, Edge, Firefox and MDN teams jointly publish Modern Web Guidance, a set of agent skills that steer coding agents away from legacy JavaScript patterns toward current web platform APIs GitHub · Hacker News 367 ptsInstalls with npx; includes a legacy-scan command for existing codebases.

"AI usage generates a fragile codebase": an engineer laid off from Meta in May, where 90% AI-generated code was the minimum for a decent rating, lists four ways agent-written code degrades a large SaaS product evanxmerz.com · Hacker News 550 ptsOne engineer's account, no data; 550 points on HN.

Evan Merz says he generated at least 90% of his code with AI in his last months at Meta and it did not even double his output; at his current employer the expectation is 100%. His four failure modes: tests that cover trivial getters and setters and leave gaps that line coverage does not show, overly complex code with needless helper methods, a codebase fewer and fewer humans understand, and pull requests arriving faster than they can be reviewed properly. The symptoms he tells teams to look for start with incidents rising slowly after the switch to agents and taking longer to mitigate because nobody knows the code. One example: a top programmer on his team tried to merge JavaScript mouseover handlers where a CSS :hover selector would do. It is one engineer's account with no data behind it.
