Mastering Emacs author releases DreamCoder, a browser-based harness for running several coding agents Mastering Emacs · HN 275Each workspace has a minimap that shows which agents are working and which are blocked waiting for you.

Mickey Petersen spent 15 months on DreamCoder and has released it after a beta test. It is a standalone coding harness with a web front end instead of a terminal UI. It has sub-agents, MCP servers, user-defined agents and terminals beside chats, laid out by a tiling window manager with keyboard navigation. Panes in the minimap pulse when an agent is working and show clearly when one is blocked on input, which is his answer to cycling through ten tmux sessions to see which agent is done. It supports open-weight models (Qwen, Gemma, DeepSeek, GLM), and he says Qwen 3.8 27B is good enough for serious local development. Much of the post is a history of Lisp, Emacs and symbolic AI. Relevant here because the fleet runs as agents in tmux panes.

Architect Labs says AI agents designed a new CPU architecture, Frostbite, from compiler to layout Architect Labs · HN 671Claimed 4.59x performance per watt, on the company's own benchmarks and against an in-order core.

The company says swarms of agents iterated on their own over the compiler, instruction set, architecture, microarchitecture, RTL, verification and final GDS layout, starting from no prior architecture. Frostbite is a general-purpose CPU built on interaction nets, where each computation step is local and each value has one owner, so parallelism comes from the program instead of out-of-order hardware. On 25 workloads, 15 of them held back until final evaluation, it claims 4.59x performance per watt against a dual-issue, in-order superscalar core that exists in silicon. The numbers are the company's own, from a design taken to layout. No chip has been fabricated or independently tested, and the baseline is not a high-end out-of-order core.
