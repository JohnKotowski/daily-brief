Training a model to make images by writing code, so the output is editable Surya Narreddi RL on Qwen where the artefact is source, not pixels — and the hard part is designing a reward for taste.

The premise is a good one: when a model hands you an image, the only way to change anything is to go back and prompt again. So Narreddi and Cameron Franz used reinforcement learning to train a language model to write code that draws the image — the code is the artefact, and code can be edited granularly. The genuinely interesting problem underneath is RL on creative work: rewards work when they're verifiable, and aesthetic quality isn't. Their answer is to move the design problem into the reward function and the criteria the judge applies — too rigid and the model converges to one look, too loose and it drifts. That tension generalises well beyond images to any agent scored on judgement rather than correctness.

FDA clears the first wearable that continuously monitors ketones and glucose together FDA Libre Duo 10 Day, cleared for ages 2 and up — aimed at catching diabetic ketoacidosis before it becomes an emergency.

The FDA authorised the Libre Duo 10 Day Continuous Dual Glucose Ketone Monitoring System: the first wearable in the US to continuously monitor ketones, and the first anywhere to track ketones and blood sugar in a single device. The clinical point is specific — rising ketones are the early warning for diabetic ketoacidosis, which currently tends to be caught once someone is already in trouble. CGM turned glucose from a finger-prick snapshot into a continuous signal and changed how the disease is managed; this is the same move applied to the complication that actually puts people in hospital.
